# Engineering notes

- **PowerShell variable interpolation can corrupt model URLs (2026-09-26).** In a double-quoted string, `$encodedPath?download=true` was parsed as one variable reference and produced a URL ending in `/=true`; Hugging Face returned 404 even though the pinned revision and file exist. Use `$($encodedPath)?download=true` and inspect the constructed URL before diagnosing the host.
- **Tauri dev needs the Windows native build environment (2026-09-26).** `npm run tauri -- dev` does not configure libclang, MSVC/Windows SDK headers, or Visual Studio's bundled CMake. `scripts/windows-build.ps1 -Task dev` sets these for the process; on a fresh checkout install `libclang` under ignored `.tools/python` or install LLVM, then use the helper.
- **Windows rejected `fsync` on a read-only decoded WAV handle (2026-09-26).** FFmpeg had finished successfully, but `os.fsync()` on a Python `rb` handle raised `OSError`, which the upload API reported as storage failure. Reopen the completed derivative as `r+b` before syncing and atomic rename.
- **A damaged ALAC frame need not invalidate an entire recording (2026-09-26).** The authorized Medpark M4A decodes to a full-length WAV while FFmpeg reports one invalid frame; `-xerror` rejected all 11 minutes. Accept recoverable output, preserve the source, and persist a generic `decodeWarning` for human review. Do not claim the missing frame contained no speech.
- **Whisper language output depends on the context window (2026-09-26).** faster-whisper's VAD concatenates retained speech before its first language detection and its `multilingual` mode detects each decoding window. Two composites with byte-identical Medpark opening PCM but different later English suffixes yielded different opening scripts under 30-second windows. Shorter 10/15-second windows restored Cyrillic but altered wording. The user confirmed the opening is Romanian, so Cyrillic is incorrect. On the full first 120 seconds, both VAD on/off and 30/15-second windows still produced Cyrillic at the opening. A public Google FLEURS-R RO/RU plus JFK English composite showed that default 30-second VAD-compressed windows mistranscribed the first Russian clip and omitted the English ending; pause-bounded clips recovered the scripts. Combining VAD clips into 25-second candidate-score windows selected Romanian for the Medpark opening but took 49.7 seconds for 120 seconds on the 8 GB laptop, so it is not yet the 15-minute solution. Keep PBI-004 open; do not infer code-switch accuracy from detected-language metadata alone.
- **Qwen GGUF runs locally with its embedded template (2026-09-26).** The pinned Q4_K_M model loaded in official llama.cpp b11200 Windows CPU and returned JSON fields for a synthetic decision prompt with reasoning disabled. The CLI's JSON-schema grammar failed when combined with its chat wrapper even though unconstrained JSON succeeded. PBI-009 must validate generated fields or use a verified structured-output path; GPU LLM speed remains unmeasured.
- **Hackathon GPU runtime needs matching Windows DLLs and inference precision (2026-09-27).** CTranslate2 4.5.0 reported CUDA support but crashed with missing cuDNN; with 12.9 CUDA libraries its `int8_float16` path failed with `CUBLAS_STATUS_INVALID_VALUE`. CTranslate2 4.8.2 + faster-whisper 1.2.1 loaded after registering local DLL directories, and FP16 completed a 60-second Medpark slice at 4,251 MiB device-wide peak. The CPU Qwen run loaded ~4.7 GiB RSS and the full 11m42s meeting took 243 seconds before exact quote validation rejected an unsupported evidence quote. Use a GPU llama.cpp runtime for the 8/16 GiB profiles; keep transcript text/checkpoints private.
- **llama-server JSON Schema output is a separate verified path (2026-09-26).** The pinned b11200 local server accepted OpenAI-compatible chat requests with `response_format: json_schema` and Qwen's `enable_thinking:false`, unlike the CLI grammar wrapper. Synthetic English decision prompts returned grounded candidates and verbatim quote IDs, but sometimes mislabeled an explicit "will call" commitment as a proposal, over-attributed the owner, and omitted date evidence. Validators now clear unsupported owner labels and preserve only literal recognized dates from cited text. A fixed seed is configured, but this remains a smoke result, not multilingual/gold acceptance. The server binds only to loopback, has an ephemeral API key, and must terminate after the job.

- **Whisper's bundled bindings are not portable to Windows (2026-09-05).** `WHISPER_DONT_GENERATE_BINDINGS=1` in whisper-rs-sys 0.15.0 selects Linux libc layouts and fails compile-time size assertions on Windows. Generate bindings with libclang instead. A repository-local pip libclang installation works when `BINDGEN_EXTRA_CLANG_ARGS` includes the installed MSVC and Windows SDK UCRT include directories; the wheel alone has no C resource headers.
- **CMake selected an unavailable VS 2026 installation on this machine.** VS 2022 BuildTools is the actual installed compiler. Setting `CMAKE_GENERATOR=Visual Studio 17 2022` resolves discovery; clear the generated CMake cache when changing generators. Build-only tools were installed under ignored `.tools/python`, with no machine-wide changes.
- **The previous ASR queue held only four WASAPI packets.** Typical packets are about 10 ms, so inference discarded most incoming speech. The ASR queue must be sized in audio time, not inference jobs, and overload must be observable. Do not restore the old queue-size setting as a packet count.
- **Overlay display text is deliberately trimmed.** Never use its stabilized/two-line string as the permanent transcript. Store the original finalized recognition text and optional translation before display trimming.

- **Packaged C++ runtime (2026-09-06).** The first embedded-ASR release linked `MSVCP140.dll`. Cargo `+crt-static`, `CMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded`, and `CMAKE_POLICY_DEFAULT_CMP0091=NEW` removed that dependency; dumpbin now lists Windows system libraries only. Recheck dependencies whenever the native engine is upgraded.
- **Controlled fixture timings.** The official whisper.cpp JFK WAV with the pinned multilingual base model recognized expected words. Before dynamic encoder context it took 7.917 seconds to process finalized streaming chunks; afterward 1.366 seconds, without audio playback. Do not report this as live audio-to-screen delay or broad language accuracy evidence.
- **Native overlay checks can stay invisible.** `--overlay-render-test` creates the normal GDI renderer without `WS_VISIBLE`, asserts the window is invisible and foreground focus unchanged, writes a BMP, and destroys the window. It is safe for layout inspection; it does not validate visible popup interaction or WASAPI.
- **Model callbacks are COM agile.** windows-implement 0.60.2 defaults `agile: true`, providing IAgileObject/IMarshal for the process-loopback completion object. Do not replace it with an apartment-bound callback.

- **Concurrent appearance edits must be patches.** Full snapshots from Settings can be older than a native move/resize or compact edit. The service serializes field patches, profile selection, shortcut toggles, and initial runtime-file preparation. The simultaneous geometry/appearance test checks durable settings and runtime-file agreement.
- **Current captions are ephemeral even on process exit.** The main process holds the scratch file with Windows FILE_FLAG_DELETE_ON_CLOSE. Normal Stop releases it; OS handle cleanup also applies if the parent exits unexpectedly. A Windows test verifies separate writes/reads remain possible while the owner exists and that closing the owner deletes the file.
- **Do not run Vite build and Vite UI tests concurrently in one checkout.** Both manage `.svelte-kit`; concurrent writes caused UI test reloads and detached locators. Keep frontend builds and browser suites sequential.
- **A borrowed PROPVARIANT needs an outer ManuallyDrop (2026-09-06).** The Windows crate implements Drop by calling PropVariantClear. Putting only the inner union in ManuallyDrop still freed the stack-backed process-loopback activation BLOB and crashed the installed app with 0xc0000374. Keep the entire borrowed variant in ManuallyDrop.
- **APPDATA environment overrides do not isolate Tauri's Windows data directory.** Tauri resolves the Windows known folder. For native validation, close the app and preserve its actual app-data directory before creating controlled test data; restore it afterward. WEBVIEW2_USER_DATA_FOLDER does isolate the test WebView profile.
- **Empty caption text crashed the actual overlay (2026-09-06).** After the 4.5-second stale threshold, an empty Vec supplied a dangling UTF-16 pointer to DrawTextW. A hidden stale-caption fixture reproduced the native exception; returning before drawing empty text fixed it. `npm run test:native-overlay` now checks current, empty and stale captions against the packaged executable.
- **Native WebView tests catch missing Tauri permissions.** Headless mocked IPC did not catch the absent `core:window:allow-start-dragging` permission. Dispatching the installed titlebar's pointer handler produced an ACL rejection; native permission checks must accompany frontend-only tests.
- **Notavra local GPU runtime and full sample (2026-09-27).** Laptop `laptop8` pins CTranslate2 4.8.2/faster-whisper 1.2.1 FP16, batch 1, and llama.cpp b11200 CUDA 12. The 11m42s Romanian upload completed to `ready` with 166 transcript segments and 35 human-review decisions. Final reconciliation returns indexes into source-validated events; evidence is reconstructed by the service so long output does not repeat every quote. The CUDA 13 llama.cpp runtime is available through the prep script but has not been run on the 5080 host.
